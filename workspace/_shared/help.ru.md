# Справка Dev Space

Dev Space объединяет материалы проекта, документы и отдельную рабочую область агентов.

## Быстрый старт

Создайте проект и тему. Напишите заметку в нижнем поле, вставьте скриншот через Ctrl+V или перетащите файл. Ctrl+Enter сохранит запись. Материалы можно перемещать между темами, архивировать и превращать в задачи.

Страница редактируется блоками или Markdown. Wiki показывает обзор на основе тех же блоков и материалов. Кнопка «Главная» открывает выбранную страницу при входе в проект.

## Агенты

Установите нужный CLI и войдите в свой аккаунт обычным способом. Нажмите «Новый агент или терминал», выберите папку проекта и явно задайте разрешения. Разделяйте рабочую область на две, три или четыре панели; вкладки можно переносить между ними.

Ctrl+Shift+O — разделить вправо, Ctrl+Shift+E — вниз, Ctrl+Shift+X — убрать панель, Ctrl+Shift+Z — развернуть панель. Удаление панели из раскладки не останавливает её агентов. Ctrl+J сворачивает область целиком.

Для оформления материалов выделите записи и выберите «Собрать страницу с агентом». Задание вставляется без отправки. Результат появляется как отдельное предложение для проверки.

## Файлы, навыки и MCP

Кнопка инструментов вверху открывает файлы, навыки и MCP. Перетаскивайте левый край панели для изменения ширины. Размер сохраняется. Через Tab можно выбрать разделитель и изменить ширину стрелками; Home или двойной щелчок возвращает стандартный размер.

Навыки можно читать и редактировать как SKILL.md. MCP показывает настройки клиентов и позволяет проверить отдельное соединение; работающий чат сохраняет собственное MCP-подключение.

## Оформление и диктовка

В Настройках доступны отдельные шрифты интерфейса и терминала, загрузка TTF/OTF/WOFF/WOFF2 и масштаб окна.

Для локального Whisper выберите Python с faster-whisper и файл model.bin совместимой модели CTranslate2. Укажите Авто, CPU или NVIDIA CUDA и нажмите «Проверить и подключить». Ctrl+Shift+Space начинает и завершает запись, Esc отменяет её. Распознанный текст остаётся черновиком. Локальная диктовка не требует оплаты API и не переключается автоматически на платный сервис.

## Хранение

Материалы и страницы находятся в workspace/devspace. Настройки и сессии — в .devspace. Загрузка в Git и стандартные пакеты исключает личные проекты, переписки, ключи и веса моделей. Передача выбранного контекста агенту использует его CLI и аккаунт.
