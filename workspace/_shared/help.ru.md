# Справка Mr. Mak

Обсуждайте задачи с агентами в **Чатах**, а результаты просматривайте и сохраняйте в **Рабочем пространстве**. Окна независимы: у рабочего пространства фиолетовая звезда, у чатов — голубая со значком сообщения.

## Язык

**Настройки → Язык интерфейса → Русский / English**. В чатах переключатель находится в меню оформления, на телефоне — в настройках телефона. Выбор сохраняется и применяется сразу. Переписки и документы остаются на исходном языке.

## Первый чат

Нажмите **+**, выберите установленного агента и рабочую папку. Дайте чату понятное название — русский язык поддерживается. Опишите результат, который хотите получить. Файлы и папки можно перетащить в чат: в сообщение добавятся их пути. Вставленное изображение сохраняется в `inbox/`.

Claude Code и Codex используют свою текущую авторизацию CLI. Для обычной переписки через поддерживаемую подписку отдельный ключ API приложения не нужен. OpenCode настраивается через собственных провайдеров; голосовой разговор и сервисы генерации используют отдельные подключения и оплату.

## Вкладки и история

Перетаскивайте вкладки, чтобы менять порядок. Правый клик открывает переименование, закрепление, цвет и выбор группы. Заголовок группы позволяет свернуть её или переместить целиком. Удаление группы сохраняет сами чаты.

Закрытый чат остаётся в **Истории**. Для восстановления полной переписки нужны также исходные файлы истории соответствующего CLI. Закрытие чата не удаляет файлы проекта.

## Карточки

Кнопка **+ Новая карточка** создаёт галерею или исследование. Нажмите **Редактировать**, чтобы добавить изображения, заметки Markdown, промпты, ссылки и статусы. Порядок записей меняется перетаскиванием или стрелками.

**Просмотр** показывает черновик. **Сохранить** записывает изменения в `.card.json`, с которым может работать и агент. При одновременных правках редактор сохраняет ваш черновик и предлагает сравнить версии. Локальные резервные копии находятся в `.mrmak/card-backups/`.

Архивирование скрывает карточку из текущего списка, сохраняя файлы и вкладки. Найти её можно через поиск или **Показать архив**. На телефоне карточки доступны для чтения; редактор находится в приложении на компьютере.

## Файлы

**Основные папки** показывают сокращённый список, **Все файлы** — дерево проекта. Выберите файл для просмотра. Изображения можно увеличить и скачать. Markdown открывается в режимах **Просмотр** и **Редактировать**; запись файла происходит по кнопке **Сохранить**.

| Папка | Назначение |
| --- | --- |
| `inbox/` | Входящие материалы и снимки экрана |
| `projects/` | Контекст и исходники проектов |
| `workspace/` | Карточки, отчёты и результаты |
| `knowledge/` | Знания для будущей работы |
| `processes/` | Рабочие процессы |
| `.claude/skills/`, `.agents/skills/` | Навыки проекта |

Перетаскивание файла в другую папку перемещает его. Delete, а на Mac ⌘⌫, отправляет выбранный элемент в корзину. Для операций с папками используйте Проводник, Finder или другой файловый менеджер.

## Навыки и MCP

**Навыки** объясняют, как выполнять задачи и проверять результаты. **MCP** подключает агента к инструменту или сервису. Настроенный сервер ещё не означает активного соединения: нажмите **Проверить**. Некоторые подключения требуют авторизации в самом агенте или запущенного приложения, например Blender.

## Голос и телефон

Нажмите кнопку со звездой, чтобы начать или закончить голосовой разговор с Mr. Mak. Для голосового соединения нужен ключ OpenAI API. Кнопка микрофона у поля ввода — отдельная диктовка; текст остаётся черновиком. Локальный Whisper позволяет диктовать без оплаты API.

Чтобы подключить телефон, откройте значок телефона в чатах, включите доступ, отсканируйте QR-код и подтвердите совпадение кодов. Tailscale должен работать на обоих устройствах. Компьютер должен оставаться включённым, а приложение — запущенным.

## Клавиши

| Сочетание | Действие |
| --- | --- |
| Ctrl+C в чате агента на Windows/Linux | Копировать выделенный текст без прерывания агента |
| Ctrl+Shift+C на Windows/Linux | Копировать выделенный текст терминала |
| Ctrl+C в обычной командной оболочке | Прервать текущую команду |
| ⌘C / ⌘V на Mac | Копировать / вставить |
| Ctrl+C на Mac | Передать прерывание в CLI |
| Ctrl+V на Windows/Linux | Вставить текст или изображение |
| Enter / Shift+Enter в поле сообщения | Отправить / новая строка |
| Ctrl+S, на Mac также ⌘S | Сохранить Markdown |
| Escape в просмотре изображения | Закрыть изображение |
| Win, если включено в настройках | Вернуть окна Mr. Mak |
| Ctrl+Esc на Windows | Открыть «Пуск» |

Разрешения CLI влияют на действия агента на компьютере. Выбирайте подходящий режим в настройках нового чата. Не включайте в Git `.env`, ключи, личные переписки и локальное состояние приложения.
