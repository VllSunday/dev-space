# Dev Space

<!-- impeccable:product-schema 1 -->

## Platform

web

React-интерфейс в отдельном настольном приложении Tauri для Windows.

## Users

Автор игровых, программных и рабочих проектов, использующий CLI-агентов. Подтверждено пользователем: одна оболочка с проектами и раскрываемой областью агентов вместо двух отдельных окон.

## Product Purpose

Собирать мысли, изображения и файлы без обязательной классификации; вручную редактировать документы; передавать выбранные материалы агенту и проверять результат перед применением.

## Operating Context

Windows, русская раскладка, keyboard shortcuts, paste/drop, локальный Whisper. Агенты работают в настоящих терминальных сессиях. Свёрнутая навигация сохраняет значки агентов и реальные состояния.

## Capabilities and Constraints

Содержимое хранится в workspace/devspace/space.json и assets; версии проверяются при записи. Агент пишет отдельное валидируемое предложение. Текущий код основан на исходниках приложения Mr. Mak с сохранением лицензий, но имеет новый Git без remote, самостоятельную identity app.devspace.desktop и имя Dev Space. Старый checkout, его Git и работающие сессии не изменяются. Служебное состояние новой версии живёт в .devspace, отдельно от .mrmak. Среда разрешает запись в Temp, но не в projects/Desktop; размещение готовых файлов проверяется отдельно.

## Brand Commitments

Dev Space, минимальная тёмная Graphite-оболочка Herdr, без звезды и маскотов. Сгенерированный знак двух панелей используется в UI, ICO, заголовке, панели задач и установщике.

## Evidence on Hand

Согласованный предыдущий интерактивный прототип и два новых референса Herdr. Подтверждённый основной игровой сценарий с универсальностью для рабочих проектов. Никакие результаты пользовательского тестирования не заявляются.

## Product Principles

Материал сохраняется без запуска модели. Сворачивание панели не останавливает агента. Состояния берутся из службы сессий. Слова автора не заменяются анализом агента. Неотправленное задание остаётся в терминале на проверку. Пользовательские данные и логины исключаются из Git и сборки.
