# Dev Space

Это независимая настольная рабочая область для проектов, материалов, документов и CLI-агентов. Общение и документы проекта ведутся на русском. Основная структура описана в README.md и PRODUCT.md.

Сохраняйте пользовательские материалы, исходные формулировки и стабильные ID. Изменения страниц проходят через типизированные операции и проверку версии. Агентские результаты сначала сохраняются как отдельные предложения. Не меняйте выбранные модель, права и провайдеры без команды владельца.

Рабочие данные находятся в workspace/devspace, служебные — в .devspace. Ни эти данные, ни .env, API-ключи, авторизации CLI и веса моделей не должны попадать в Git или дистрибутив. Не прерывайте существующие агентские сессии ради обновления.

Проверяйте изменённые сценарии. TypeScript и Vite проверяются через npm run build; связанные тесты указаны в README. Успешная сборка не является доказательством native UI, микрофона или распознавания. Сообщайте фактические границы проверок.
