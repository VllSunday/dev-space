# Dev Space 1.0.5

- Добавлен встроенный учебный проект «Острова ветра»: Wiki, темы, шесть страниц, 12 материалов, три GLB-модели и шесть задач.
- «Посмотреть пример» доступно на пустом экране. В окне «Новый проект» есть «Открыть учебный проект»; также работает палитра Ctrl+K.
- Каждый импорт создаёт независимую редактируемую копию с новыми ID и вложениями. Существующие проекты не заменяются, агент автоматически не запускается.
- Учебный шаблон с исходниками и ассетами включён в репозиторий и пакеты приложения.
- README дополнен настоящими полноразмерными скриншотами четырёх работающих CLI-панелей, Wiki, настроек и 3D viewer.

Содержит изменения 1.0.4: отдельные экраны тем и галерей, до восьми превью на главной, переход к записи, история, сохранность Markdown, регулируемая панель Файлы/Навыки/MCP и тема Graphite.

Пакеты: Windows x64, Linux x86_64, macOS arm64 и x64. Portable-архив распаковывайте полностью вместе с runtime. Телефоны подключаются через браузер к компьютеру. macOS использует ad-hoc подпись без notarization. SHA256SUMS.txt содержит контрольные суммы.

Личные материалы, переписки, CLI-логины, API-ключи и веса Whisper в пакеты не входят.
