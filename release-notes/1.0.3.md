# Dev Space 1.0.3

## Рабочее пространство

- Проекты, темы и быстрые заметки с изображениями и файлами.
- Страницы с редактором блоков, Markdown и Wiki; выбор главной страницы проекта.
- Локальный GLB viewer с режимами материалов, сетки и нормалей.

## Агенты и оформление

- До четырёх терминальных панелей с переносом вкладок и изменяемыми пропорциями.
- Ctrl+Shift+O/E/X/Z: разделить вправо, разделить вниз, убрать или развернуть панель.
- Отдельные шрифты интерфейса и терминалов, загрузка файлов шрифтов и масштаб окна.
- Настройка локального Whisper через UI с проверкой Python, модели и CPU/CUDA.

## Изменения 1.0.3

- Панель «Файлы / Навыки / MCP» меняет ширину перетаскиванием левого края. Размер сохраняется между запусками.
- Разделитель доступен с клавиатуры: Tab, стрелки, Home. Двойной щелчок возвращает стандартную ширину.
- Единая тёмная Graphite-тема для списков навыков, MCP, полей, кнопок и состояний.
- Обновлены название, справка, сообщения и README.

## Пакеты

Windows x64, Linux x86_64, macOS arm64 и macOS x64. Для переносного запуска нужен весь архив с папкой runtime. Контрольные суммы — SHA256SUMS.txt. На macOS используется ad-hoc подпись без notarization. Телефоны подключаются через браузер к компьютеру; отдельные мобильные пакеты не создаются.

Личные проекты, переписки, локальные игровые примеры и модели Whisper в пакеты не входят.
