# Dev Space 1.0.7

- Исправлена подготовка тестовых панелей агентов в Windows CI: короткое имя папки RUNNER~1 и полное имя runneradmin теперь разрешаются до создания тестовых сессий.
- Проверка ждёт появления всех четырёх вкладок перед проверкой разделения, переноса, закрытия и изменения размеров панелей. Все проверки остаются включены.

Включены изменения 1.0.6: корректная проверка путей Whisper, обновлённая библиотека терминалов и тест одновременного завершения шести оболочек.

Также доступны встроенный учебный проект «Острова ветра», Wiki с отдельными темами и галереями, три GLB-модели, четыре панели агентов, свои шрифты, диктовка и регулируемая панель Файлы/Навыки/MCP.

Пакеты: Windows x64, Linux x86_64, macOS Apple Silicon и Intel. Portable-архив нужно распаковать полностью вместе с runtime. Телефоны подключаются к компьютеру через браузер. macOS: ad-hoc подпись без notarization. SHA256SUMS.txt содержит контрольные суммы.

Личные материалы, переписки, CLI-логины, API-ключи и веса Whisper в пакеты не включены.
