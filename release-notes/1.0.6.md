# Dev Space 1.0.6

Исправлен выпуск пакетов для Windows, Linux и macOS.

- Проверка подключения Whisper корректно учитывает канонические пути macOS и короткие имена папок Windows.
- Библиотека терминалов обновлена до node-pty 1.2.0-beta.14 с исправлением многопоточного доступа к списку Windows-консолей. Версия закреплена; обновление проверяется настоящими PTY-тестами на каждой платформе.
- Добавлена проверка одновременного завершения шести терминалов с сохранением их вывода.

Включены все возможности 1.0.5: встроенный редактируемый проект «Острова ветра», Wiki, темы и галереи, три GLB-модели, четыре панели агентов, настройка шрифтов, диктовка и регулируемая панель Файлы/Навыки/MCP.

Windows x64: установщик или полностью распакованный portable-архив. Linux x86_64: AppImage или portable-архив. macOS: отдельные пакеты для Apple Silicon и Intel, ad-hoc подпись без notarization. Телефоны подключаются к компьютеру через браузер. Контрольные суммы находятся в SHA256SUMS.txt.

Личные проекты, переписки, CLI-логины, API-ключи и веса Whisper в пакеты не входят.
