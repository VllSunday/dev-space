# Независимый режим каждого чата

Причина ошибки: `saveChatView` записывал как режим чата, так и общий ключ `mrmak.chatView.default`. Чаты без личной настройки читали этот ключ на следующем рендере и тоже переключались.

Теперь сохраняется только режим конкретного ID. Старое общее значение игнорируется, индивидуальные настройки остаются. Новый чат открывается в терминале. При недоступном браузерном хранилище выбор сохраняется в памяти этого окна отдельно для каждого ID. Переход из пустой переписки в терминал использует тот же независимый путь.

Проверки: 35 связанных тестов прошли, включая четыре регрессии для независимости режимов, повторной загрузки модуля, неподдерживаемых CLI и ошибки хранилища. TypeScript, ESLint файла состояния и Vite проходят. Пакет проверяется по хешам и отдельным сервисным сценарием. Визуальная проверка многопанельного интерфейса недоступна: ранее запуск браузера блокировался ошибкой spawn EPERM. Реальные агенты для проверки не запускались и не останавливались.
