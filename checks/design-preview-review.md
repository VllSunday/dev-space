# Локальный предпросмотр согласованного дизайна

## persistence

Wiki остаётся необязательной и создаётся при первом закреплении. Старые страницы
читаются без перезаписи при открытии. Новая композиция хранит ссылки на блоки
и темы того же проекта. Операции проверяют версии; удаление коллекции сохраняет
материалы. Изменения участвуют в существующей истории.

## fidelity

Перенесены Graphite-композиция Wiki, generic list/tiles/gallery, вставки между
разделами, рабочие handles и меню, значки/описания тем, режим перехода из
редактора, компактная навигация, панели без внутренних рамок и effort на
английском. Новый векторный набор используется также в системных кнопках и
логотипах агентов. Главный знак собран из кода в PNG/SVG/ICO/ICNS. Баннер README
заменён присланным изображением. Для native select задана тёмная палитра.

## ceiling

Один независимый статический finish review. Браузерный запуск заблокирован
`spawn EPERM`; Playwright MCP не нашёл Chrome. Новых снимков приложения нет.
Визуальный результат, native dropdown и drag/focus требуют просмотра сборки.

## material_fixes

Исправлены найденные reviewer случаи: переносы в contentEditable сохраняются
через innerText; patch темы не воскрешает удалённый блок; повторные коллекции
не исчезают после pin; отменённый drag очищается; Markdown следует композиции;
новый блок получает фокус по стабильному ID. Регрессии сохранности покрыты
профильными тестами.

## verdict

TypeScript, Vite, native Windows EXE, lint изменённых компонентов и 23 профильных
теста прошли. Полный набор тестов не подтверждён: широкий запуск остановлен
после сбоя существующего real-PTY сценария Antigravity. Browser fixtures
обновлены, но не выполнены в этой сессии. Комплект для локального просмотра
проверен по SHA-256; это не опубликованный релиз.
