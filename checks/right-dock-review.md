# Правый dock · локальная сборка для просмотра

## persistence

Порядок DOM изменён на навигация → документ → разделитель → агенты. Сессии,
ID панелей, проектные файлы и формат flow этой правкой не меняются. Установщик
ждёт ручного выхода из приложения и сохраняет предыдущий комплект.

## fidelity

Единственное меню проекта слева; внутреннего меню Wiki нет. Главная имеет
отдельный пункт и не дублируется в списке страниц. Системная галерея названа
«Все изображения». Исправлен row-layout превью. Постоянный native scrollbar
xterm скрыт, custom overlay сохранён. Прежние Icon/AgentLogo и PNG/ICO/ICNS
восстановлены; effort выводится без перевода.

## ceiling

Одна независимая статическая проверка новой дельты, без новых GUI-снимков.
Браузерные проверки в этой среде недоступны из-за spawn EPERM; их сценарии
обновлены для правой геометрии, resize и единственной навигации.

## material_fixes

Исправлена найденная граница 901–919 px: до 920 px агенты открываются поверх
документа справа. Desktop resize меняет ширину в правильном направлении;
режим разворачивания использует всю рабочую область. Layout fixture теперь
включает 901, 919, 920, 960, 1280, 1920 и 2560 px и проверяет мышь/клавиатуру.

## verdict

TypeScript, Vite, 23 профильных теста данных и native Windows compilation
прошли. Полный комплект EXE/runtime упакован с SHA-256. Реальный UI после
изменения раскладки ещё требует просмотра пользователем. Это локальный билд,
а не опубликованный релиз.
