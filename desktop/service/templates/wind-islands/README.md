# Острова ветра · учебный шаблон

Небольшой пример рабочего проекта: Wiki, игровой дизайн, три локации, карта маршрута, галерея референсов, три GLB-модели, задачи и инструкция по работе.

В приложении нажмите **Новый проект → Открыть учебный проект**. На пустом экране материалов та же кнопка называется **Посмотреть пример**. Создаётся отдельная редактируемая копия: исходники шаблона и существующие проекты не меняются. Повторный импорт создаёт ещё одну копию.

Внутри:

- `template.json` — один проект, пять тем, шесть страниц, 12 материалов и шесть учебных задач;
- `assets/demo-wind-hero.png` — сгенерированная иллюстрация концепта;
- `assets/demo-wind-map.svg` — схема маршрута;
- `assets/*.glb` — собственные учебные blockout-модели курьера, маяка и острова.

Это пример организации проекта, а не готовая игра или финальные игровые ассеты. Иллюстрация сгенерирована для примера, схема и модели созданы для него из простых форм. Материалы распространяются на условиях MIT-лицензии этого репозитория.

В наборе нет переписок, ключей, настроек агентов и абсолютных путей конкретного компьютера. При импорте приложение создаёт новые ID и копирует вложения в локальное хранилище. Поэтому файлы можно редактировать, не затрагивая другую копию примера.
